# ADR 0009: VirusTotal の検出の閾値

- 状態: 置き換え済み (2026-11-09、[ADR 0012](0012-drop-virustotal.md))
- 決定日: 2026-11-09

## 背景

VirusTotal のハッシュ照会は、ファイルを解析した各エンジンの判定の件数を `last_analysis_stats` として返します。件数は `malicious`・`suspicious`・`undetected` などの区分ごとに分かれます。

数十のエンジンのうち 1〜2 件だけが `malicious` と判定する事例には、誤検知が含まれます。検出 1 件で停止すると、誤検知を受けた正当なプラグインが掲載から外れます。一方で、要件は検査できない状態や検出の兆候を安全と解釈しないことを求めています。

## 決定

VirusTotal の判定の件数から、検査結果を次のように決めます。

| 条件 | 検査結果 | 掲載への影響 |
| --- | --- | --- |
| `malicious` が 3 エンジン以上 | `malicious` | プラグインを停止する |
| `malicious` が 1〜2 エンジン、または `suspicious` が 1 エンジン以上 | `suspicious` | リリースを検査済みにせず、掲載を保留する。管理者が判断する |
| 上のいずれにも当てはまらない | `clean` | 確定した結果とみなす |

閾値は `src/scanners.ts` の `VIRUSTOTAL_MALICIOUS_THRESHOLD` で定めます。

## 検討した選択肢

| 選択肢 | 評価 |
| --- | --- |
| 3 エンジン以上で停止し、それ未満の検出を保留する | 採用しました。少数のエンジンの誤検知で停止しません。検出の兆候があるリリースは掲載しません。 |
| 1 エンジン以上で停止する | 誤検知でも停止します。停止の解除には管理者の操作が要ります。 |
| 少数のエンジンの検出を `clean` と同じに扱う | 検出の兆候を安全と解釈することになり、要件に反します。 |

## 影響

`suspicious` の配布物を持つリリースは、管理者が判断するまで掲載されません。より古い検査済みのリリースがあれば、そのリリースが掲載対象バージョンとして残ります。

管理者は、停止すると判断した場合に管理用スクリプトで停止します。手順は [掲載停止と再開](../operations/suspend.md) に記載します。掲載を認めると判断した場合は、管理用スクリプトの `approve-suspicious` で結果を `clean` に変えます。

MalwareBazaar は既知のマルウェアの検体だけを収録するため、収録があれば `malicious` とします。本判断の閾値は MalwareBazaar に適用しません。
