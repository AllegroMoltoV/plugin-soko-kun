# 0011 プラグインの画像を Worker から配信する

- 状態: 採用 (2026-11-09)

## 背景

依頼者が、プラグインのロゴを一覧と詳細に、説明の画像を詳細に 1 枚ずつ表示することを求めました。GIF はアニメーションとして再生します。画像は作者が用意する外部データで、掲載後に差し替えられる可能性があります。

## 決定

作者がリポジトリの `.soko-kun/` に置いた画像を、同期のときに最新リリースのタグの時点で取得します。Worker は形式と大きさを確かめてから D1 に保存し、自分のドメインから配信します。形式は PNG・JPEG・GIF・WebP に限り、SVG は受け付けません。

## 検討した選択肢

| 選択肢 | 判断 |
| --- | --- |
| Worker が取得して D1 に保存し、自分のドメインから配信する | 採用しました。確かめた画像だけを配信でき、CSP の画像の取得先を自サイトに限ったままにできます |
| GitHub 上の画像へ直接リンクする | 採用しませんでした。掲載後に作者が画像を差し替えられます。また、閲覧者の IP アドレスが GitHub に渡ります |
| KV に保存する | 採用しませんでした。KV の無料枠の書き込みは 1 日 1,000 件で、OAuth の経路と分け合うためです |
| 登録のときに AI エージェントから画像のパスを指定してもらう | 採用しませんでした。画像を変えるたびに登録し直す必要があります |
| SVG を受け付ける | 採用しませんでした。SVG はスクリプトを含められ、直接開いたときに実行されるおそれがあります |

## 影響

作者が画像を変えるには、新しいリリースを公開します。D1 の 1 行の上限が 2 MB のため、説明の画像は 1.5 MB までです。不適切な画像は、管理コマンドで画像だけを非表示にできます。スクリプトを使わないため、動きを減らす設定の閲覧者に対しても GIF の再生を止められません。
