# ADR 0006: VirusTotal の未登録の扱い

- 状態: 未決定
- 起票日: 2026-11-09

## 背景

本サービスは、配布物の `digest` を VirusTotal の Public API へ照会します。VirusTotal のハッシュ照会は、VirusTotal が既にそのファイルを解析している場合だけ結果を返します。未解析のファイルでは結果が得られず、本サービスは検査結果 `not_found` を記録します。

VirusTotal の未登録は、MalwareBazaar の未登録と意味が異なります。VirusTotal は既知のマルウェアに限らずファイルを収録するため、未登録は解析が行われていないことを示します。新しいリリースの配布物は未登録であることが多いと推測します。

未登録のファイルを解析させるには、ファイルを VirusTotal へアップロードする必要があります。本サービスは Worker で配布物をダウンロードしないため、現在の構成ではアップロードできません。ダウンロードしない判断は [ADR 0003](0003-github-digest-without-download.md) に記載しています。

あわせて、VirusTotal の Public API を本サービスで利用できることも確認中です。Public API には商用の製品やサービスでの利用を禁じる条項があり、非営利の OSS レジストリへの適用を VirusTotal へ問い合わせています。

## 決定

未決定です。VirusTotal からの回答を受けて、依頼者が判断します。

決定までの間、VirusTotal の `not_found` は未検査として扱います。この扱いでは、VirusTotal に未登録の配布物を持つリリースは検査済みになりません。そのリリースしか持たないプラグインは検査待ちのまま残ります。

## 検討した選択肢

| 選択肢 | 評価 |
| --- | --- |
| 有料プランへ切り替え、配布物をアップロードして解析させる | 未登録の配布物も検査できます。固定費が生じます。提出したファイルの解析結果は VirusTotal のコミュニティに共有されます。 |
| 検査不能として掲載を保留する | 現在の構成のまま運用できます。未登録の配布物を持つリリースは掲載されません。 |
| `not_found` を `clean` と同じに扱う | 掲載は進みます。検査できない状態を安全と解釈しないという要件に反するおそれがあります。 |
| VirusTotal を照会先から外す | Public API の利用条件の問題はなくなります。照会先が MalwareBazaar だけになり、検出できる範囲が狭くなります。 |

## 影響

決定までの間、実データでの自動掲載は確認できません。掲載への遷移は、状態の算出の単体テストと、検査結果を直接与えたローカルでの確認で示します。

算出の実装は、VirusTotal の `not_found` の扱いを設定値として受け取ります。既定値は未検査です。`clean` と同じに扱う案、または保留する案に決まった場合は、この設定値で対応できます。アップロードする案に決まった場合は、配布物の取得とアップロードの処理を新たに設計する必要があります。
