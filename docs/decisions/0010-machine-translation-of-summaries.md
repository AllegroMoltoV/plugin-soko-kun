# 0010 プラグインの説明文の機械翻訳

- 状態: 採用 (2026-11-09)

## 背景

プラグインの概要は、作者が GitHub に書いた言語のままです。7 言語の利用者に向けて、概要を画面の言語で読めるようにすることを、依頼者が求めました。以前は概要を原文のまま表示し、機械翻訳しない方針でした。この判断はその方針を改めます。

## 決定

同期で概要が変わったときに、Workers AI の翻訳モデル `@cf/meta/m2m100-1.2b` で 6 言語へ翻訳し、D1 に保存します。画面には保存した翻訳を表示し、自動翻訳である旨と原文を表示するリンクを添えます。MCP の応答には原文を返します。

## 検討した選択肢

| 選択肢 | 判断 |
| --- | --- |
| Workers AI の m2m100-1.2b を使う | 採用しました。無料プランで 1 日 10,000 Neurons まで使えます。概要 1 件を 6 言語へ訳すと約 56 Neurons の試算です。翻訳専用のモデルのため、概要に書かれた指示に従って出力を変える心配が小さいと考えています |
| 外部の翻訳 API を使う | 採用しませんでした。API キーの取得と外部への送信が増えます |
| 画面の表示のたびに翻訳する | 採用しませんでした。表示のたびに無料枠と時間を使います |

## 影響

m2m100-1.2b は中国語の繁体字に対応しないため、`zh-Hant` の画面には簡体字への翻訳を表示し、その旨を示します。無料枠を使い切った日は翻訳が次回以降に回り、その間は原文を表示します。翻訳の品質は、利用者の通報で問題を把握します。
