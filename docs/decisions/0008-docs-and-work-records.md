# ADR 0008: 公開文書と作業記録の分担

- 状態: 採用
- 決定日: 2026-11-09

## 背景

本リポジトリは公開されます。開発の過程では、調査報告・実行ログ・計画・確認事項のような作業記録が生じます。作業記録には、検討途中の仮説や、公開に向かない環境の情報が含まれます。

一方で、利用者と貢献者には、製品の現在の設計と確定した判断を示す必要があります。

## 決定

`docs/` には、公開する文書だけを置きます。対象は、用語集・設計判断の記録・設計文書・運用手順です。文書は日本語で書きます。文書の索引は [docs/INDEX.md](../INDEX.md) です。

調査報告と実行ログは公開せず、git の追跡対象外に置きます。作業の状態と計画も、git の追跡対象外の課題管理に置きます。

設計判断の記録に書いた判断は、作業記録から参照します。同じ判断を両方に書きません。

公開文書が非公開の調査を根拠にする場合は、非公開の検証記録とだけ記載します。

## 検討した選択肢

| 選択肢 | 評価 |
| --- | --- |
| 公開文書と作業記録を分け、作業記録を公開しない | 採用しました。公開文書を現在の状態だけに保てます。 |
| 調査報告と実行ログも `docs/` に置いて公開する | 判断の根拠を誰でも確認できます。公開に向かない情報の除去を記録ごとに行う必要があります。 |
| 設計を作業記録だけに置く | 利用者と貢献者が設計を参照できません。 |

## 影響

公開文書の根拠のうち、非公開の検証記録に依存するものは、第三者が確認できません。根拠の要点は、各文書の本文に記載します。
