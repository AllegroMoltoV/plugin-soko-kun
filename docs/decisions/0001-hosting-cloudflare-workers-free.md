# ADR 0001: ホスティング基盤

- 状態: 採用
- 決定日: 2026-11-09

## 背景

本サービスは、MCP エンドポイント・Web カタログ・定期同期・永続データを 1 つのアプリケーションで提供します。利用量は当面小さいと見込んでいます。固定費を避け、運用の手間を減らすことが求められます。

基盤には、MCP サーバーと OAuth の認可サーバーを実装しやすいこと、定期実行の仕組みを持つこと、軽量なデータベースを使えることが必要です。

## 決定

Cloudflare Workers の無料プランを使います。データベースは D1、OAuth の状態の保存は KV、定期実行は Cron Triggers で賄います。

無料プランの上限に達した時点で、有料プランへの切替えを検討します。有料プランの費用は最低 5 USD/月です。

## 検討した選択肢

| 選択肢 | 評価 |
| --- | --- |
| Cloudflare Workers の無料プランと D1 | 採用しました。MCP の SDK と OAuth の認可サーバーのライブラリが Workers 上で動きます。定期実行は設定ファイルに書くだけで使えます。 |
| Cloudflare Workers の有料プラン | 1 回の起動の CPU 時間と外部呼び出しの上限が大きく、設計の制約が減ります。固定費が生じるため、上限に達するまで使いません。 |
| Vercel と Turso | 無料プランが個人の非商用利用に限られます。認可サーバーを別途用意する必要があります。 |
| Fly.io と SQLite | 新規の組織に無料枠がなく、固定費が生じます。認可サーバーを別途用意する必要があります。 |

## 影響

無料プランの上限が設計の前提になります。1 回の起動あたり CPU 時間は 10 ms、外部呼び出しは 50 件、D1 のクエリは 50 件に制限されます。KV の書き込みは 1 日 1,000 件に制限されます。これらの制約から、配布物を Worker でダウンロードしない判断 [ADR 0003](0003-github-digest-without-download.md) と、検査を Cron で進める判断 [ADR 0007](0007-asynchronous-scanning-with-cron.md) が導かれます。

本サービスは、上限に収まるよう処理ごとに予算を設けます。予算の値は [検査と同期](../design/scanning.md) に記載します。

Cron Triggers の個数はアカウント単位で共有されます。本サービスが使う Cron Trigger は 1 個です。
