# 画面構成

Web カタログの画面の一覧と、各画面に置く要素の仕様です。Web カタログは閲覧専用で、プラグインの登録は MCP の `submit_plugin` だけで受け付けます。

## 共通の仕様

| 項目 | 仕様 |
| --- | --- |
| スクリプト | 使わない。検索はフォームの送信で行う |
| 出力の無害化 | Hono の JSX の自動エスケープを使い、生の HTML を出力しない |
| 応答ヘッダー | `Content-Security-Policy` は `default-src 'none'` を基本とし、スタイルシートと画像とフォームの送信先を自サイトに限る。`X-Content-Type-Options: nosniff`・`Referrer-Policy: strict-origin-when-cross-origin`・`X-Frame-Options: DENY` を付ける |
| 外部データ | 概要は画面の言語へ機械翻訳して表示し、自動翻訳である旨と原文を表示するリンクを添える。リリース名と配布物名は GitHub の原文のまま表示する |
| リンク | 本文と固定ページに書く URL は、すべてリンクにする |
| 掲載の範囲 | 一覧に出すのは掲載中のプラグインだけ |
| モバイル表示 | 幅 760 px 以下で 1 段組みに切り替える。幅 320 px まで、画面の右端からはみ出す要素を作らない |
| スクロール | 画面全体の縦方向のスクロールだけを使う。要素の中のスクロールと横方向のスクロールは使わない |

## 見た目の方針

2000 年代前半のソフトウェア紹介サイトの見た目に合わせます。特定のサイトの模倣はしません。

| 項目 | 仕様 |
| --- | --- |
| 幅 | 本文と右の列を、最大幅 860 px で中央に寄せる |
| 文字 | 基本の大きさは 13 px。見出しは 17 px、注記は 11 px |
| 見出しの帯 | 上部の帯と右の列の見出しは、テーマカラーのグラデーションで塗る |
| 罫線 | 区画は 1 px の灰色の罫線で囲む。角は丸めない |
| リンク | 下線を付ける |
| ボタン | 上と左を明るく、下と右を暗くした立体的な枠で描く。ダウンロードボタンだけをテーマカラーで塗る |
| 検索ボタン | 虫眼鏡の図だけを表示する。図は HTML に直接書いた SVG で描き、読み上げ用の文字を見えない形で添える |
| 上部の帯の部品 | 検索欄、検索ボタン、言語のボタンを同じ高さにし、縦の中央でそろえる |
| 暗い配色 | ブラウザの設定 (`prefers-color-scheme`) に従って、明るい配色と暗い配色を切り替える。画面上の切替えは置かない。暗い配色でも「配色の規則」を保つ |

## 配色の規則

色は、テーマカラーの緑と、白・灰・黒の無彩色だけを使います。カテゴリのタグもテーマカラーで表示し、カテゴリごとに色を分けません。

例外の色は次の 2 つです。どちらも安全に関わる表示に限ります。

| 色 | 使う表示 | 理由 |
| --- | --- | --- |
| 赤 | 掲載停止と掲載終了の状態 | 利用者に危険の表示を見落とさせないため |
| 黄 | 検査中の状態と注意書き | 安全に関わる注意を、ほかの情報と区別させるため |

新しい色を加えるときは、この表に色・使う表示・理由を書き足してから使います。

## 文言の規則

画面と固定ページの文言は、次の規則で書きます。

- 主語を文頭に置き、主語と述語の対応を明らかにする。
- 利用者に求める行動は「〜してください」と書く。
- 1 つの文には 1 つの主張を入れる。事実だけで終わらせず、その事実を理由に利用者が取るべき行動まで 1 文で書く。
- 日本語の文言は yomiyasu で推敲する。ほかの言語の文言は、推敲した日本語の意味に合わせて書く。

全ページ共通の注意書きは、次の 2 文です。

> このプラットフォームは OBS Project と無関係の非公式で無料のサービスです。各プラグインの安全性を保証しないので、個人の責任にもとづき注意して利用してください。

配布物を GitHub から直接ダウンロードすることは、注意書きには書かず、概要ページとダウンロードボタンの近くに書きます。

## 画面の一覧

| パス | 画面 |
| --- | --- |
| `/` | トップと検索 |
| `/?q=...&os=...&category=...` | 検索結果 |
| `/?category=...` | カテゴリ別の一覧 |
| `/plugins/<owner>/<repo>` | プラグインの詳細 |
| `/about` | 概要と掲載ポリシー |

## 全ページ共通の枠

画面は、上から順に次の要素で構成します。

| 要素 | 内容 |
| --- | --- |
| 上部の帯 | サービス名・キーワードの検索欄・言語の一覧。ロゴは画像を使わずサービス名の文字で表す |
| カテゴリの帯 | その他を除く 7 カテゴリと、すべての一覧へのリンク |
| 注意書き | 「文言の規則」に書いた 2 文 |
| 本文 | 各画面の内容。右の列を除いた残りの幅 |
| 右の列 | 幅 230 px。内容は下表 |
| 下部 | 固定ページへのリンク、本サービスのソースコードへのリンク、「© 2026 AllegroMoltoV」の表記 |

右の列には、本文と重ならない情報を置きます。

| 区画 | 内容 |
| --- | --- |
| 新着 5 件 | 掲載中のプラグインを掲載日の新しい順に 5 件。名前・カテゴリ・掲載日 |
| AI エージェントから使う | MCP で接続すると会話でプラグインを探せること、作者は会話で登録できること、話しかけ方の例、`/about` の接続方法へのリンク |
| 掲載と検査について | 作者本人が登録すること、配布物を既知のマルウェアのデータベースと照合すること、検出なしは安全の保証ではないこと、`/about` と `/report` へのリンク |
| 倉庫の状況 | 掲載中の件数と最終同期の日時 |
| プラグインを登録する | 作者向けに、`/submit` への案内 |

幅 760 px 以下の表示では、右の列を本文の下へ移します。カテゴリの帯は折り返して表示します。言語の一覧は、開いたときに本文の上へ重ねず、帯の中に広げて表示します。注意書きは短縮し、詳細へのリンクを添えます。

## カテゴリ

| 表示名 | `category` の値 |
| --- | --- |
| 音声フィルター | `audio-filter` |
| 映像フィルター | `video-filter` |
| 入力ソース | `source`。配信画面に映像や音声を足すもの |
| トランジション | `transition` |
| ドック・パネル | `dock-ui`。OBS Studio の画面にドックやパネルを足すもの |
| 配信・録画 | `output` |
| その他 | `other`。どれにも当たらないもの |

カテゴリは、作者が登録のときに選びます。選ばなかった場合は自動で推定し、管理者は管理コマンドで直せます。OBS Forums のリソースの分類は OBS Studio Plugins の中を種類で分けていないため、OBS Studio の画面で使う言葉で分けています。カテゴリはテーマカラーのタグで表示します。推定の規則は [検査と同期](scanning.md) に記載します。

## トップと検索

| 要素 | 内容 |
| --- | --- |
| カテゴリのタグ | 全カテゴリへのリンク |
| 検索フォーム | キーワードの入力欄と、OS の選択。OS の選択肢はすべて・Windows・macOS・Linux |
| 新着・更新 | 掲載中のプラグインのカード。もっと見るへのリンク |

プラグインのカードは、名前・掲載対象バージョン・カテゴリのタグ・対応 OS のタグ・概要・作者・更新日を表示します。カードには状態のバッジを出しません。

## 検索結果とカテゴリ別の一覧

| 要素 | 内容 |
| --- | --- |
| 見出し | 検索語またはカテゴリと、件数 |
| 絞り込み | OS とカテゴリ |
| 並び順 | 更新の新しい順 |
| 一覧 | トップと同じ形のカード |
| ページ送り | 前へ・現在のページと総ページ数・次へ。1 ページは 20 件 |

## プラグインの詳細

掲載中のプラグインの詳細ページは、上から順に次の要素で構成します。

| 要素 | 内容 |
| --- | --- |
| パンくずリスト | ライブラリとカテゴリ |
| 見出し | 名前・カテゴリのタグ・概要。掲載中であることは表示しない。一覧と詳細には掲載中のプラグインしか出ないため |
| ダウンロードボタン | GitHub の配布物へ直接リンクする。掲載対象バージョン・配布物名・サイズを添える |
| 基本情報 | 作者・対応 OS・対応 OBS バージョン・ライセンス・バージョンと公開日・コミット SHA・GitHub リポジトリへのリンク・GitHub のリリース一覧へのリンク |
| 配布物と検査 | 配布物ごとの名前・SHA-256・検査結果・検査日時。スキャナーごとの結果。検出なしは安全の保証ではない旨 |
| 検査中の新しいバージョン | 掲載対象より新しいリリースが検査中のとき、その旨と、検査が終わるまで掲載対象バージョンを示す旨 |
| 注意事項 | 配布物は作者が GitHub で公開したものであること、導入前に作者の説明を読むこと |
| 通報 | `/report` へのリンク |

対応 OBS バージョンは、確認できない場合に確認できない旨を表示します。

右の列には、全ページ共通の区画の前に、この作者のプラグインと、同じカテゴリの新着を置きます。

掲載中以外のプラグインの詳細ページは、次の要素だけで構成します。ダウンロードボタン・概要・配布物と検査の区画は表示しません。応答には `X-Robots-Tag: noindex` を付け、検索エンジンに載せません。

| 要素 | 内容 |
| --- | --- |
| パンくずリストと見出し | 名前・カテゴリのタグ・状態のバッジ (検査中、掲載停止、掲載終了) |
| 案内文 | 検査待ちでは、検査を通るとダウンロードの案内を表示する旨。停止では、掲載を停止している旨。掲載終了では、GitHub で公開されなくなった旨 |
| 理由 | 停止で、管理停止の理由が設定されている場合だけ表示する |
| 通報 | `/report` へのリンク |

右の列には、全ページ共通の区画だけを置きます。

## 固定ページ

| パス | 内容 |
| --- | --- |
| `/about` | サービスの目的、非公式であること、配布物を GitHub から直接ダウンロードすること、掲載条件、AI の使用の有無を掲載の条件にしないこと、Claude Code と Codex での MCP の接続方法と話しかけ方の例 |
| `/submit` | 作者向けに、登録の条件、MCP の接続とサインイン、話しかけ方の例、登録後の流れ (検査に要する時間と状態の変化)、登録が拒否されたときの理由と直し方の一覧、更新と掲載の取り下げの方法 |
| `/security` | 検査の内容と限界、掲載は安全性の保証ではないこと、免責 |
| `/report` | 公開してよい内容は GitHub Issues、マルウェアの疑いのような非公開の内容は GitHub の Private vulnerability reporting で受け付けること |
| `/privacy` | 保存する個人情報と利用目的 |

英語以外の固定ページには、翻訳は参考であり英語版が正である旨と、英語版へのリンクを表示します。言語の仕様は [多言語対応](i18n.md) に記載します。
