# 画面構成

Web カタログの画面の一覧と、各画面に置く要素の仕様です。Web カタログは閲覧専用で、プラグインの登録は MCP の `submit_plugin` だけで受け付けます。

## 共通の仕様

| 項目 | 仕様 |
| --- | --- |
| スクリプト | 使わない。検索はフォームの送信で行う |
| 出力の無害化 | Hono の JSX の自動エスケープを使い、生の HTML を出力しない |
| 応答ヘッダー | `Content-Security-Policy` は `default-src 'none'` を基本とし、スタイルシートと画像とフォームの送信先を自サイトに限る。`X-Content-Type-Options: nosniff`・`Referrer-Policy: strict-origin-when-cross-origin`・`X-Frame-Options: DENY` を付ける |
| 外部データ | 概要は画面の言語へ機械翻訳して表示し、自動翻訳である旨と原文を表示するリンクを添える。リリース名と配布物名は GitHub の原文のまま表示する |
| リンク | 本文と固定ページに書く URL は、すべてリンクにする。置き換え用の語 (`<owner>` など) を含む例の URL はリンクにしない |
| 固定ページの書式 | コマンドはコードブロックで示す。並列の条件や一覧は箇条書きで示す |
| 掲載の範囲 | 一覧に出すのは掲載中のプラグインだけ |
| モバイル表示 | 幅 760 px 以下で 1 段組みに切り替える。幅 320 px まで、画面の右端からはみ出す要素を作らない |
| スクロール | 画面全体の縦方向のスクロールだけを使う。要素の中のスクロールと横方向のスクロールは使わない |

## 見た目の方針

2000 年代前半のソフトウェア紹介サイトの見た目に合わせます。特定のサイトの模倣はしません。

| 項目 | 仕様 |
| --- | --- |
| 幅 | 本文と右の列を、最大幅 860 px で中央に寄せる |
| 文字 | 基本の大きさは 13 px。見出しは 17 px、注記は 11 px |
| 見出しの帯 | 上部の帯と右の列の見出しは、主の色のグラデーションで塗る。本文の見出しの帯は副の色で塗る |
| 罫線 | 区画は 1 px の灰色の罫線で囲む。角は丸めない |
| リンク | 下線を付ける |
| ボタン | 上と左を明るく、下と右を暗くした立体的な枠で描く。ダウンロードボタンだけを主の色で塗る |
| 検索ボタン | 虫眼鏡の図だけを表示する。図は HTML に直接書いた SVG で描き、読み上げ用の文字を見えない形で添える |
| 上部の帯の部品 | 検索欄、検索ボタン、言語のボタンを同じ高さにし、縦の中央でそろえる |
| 暗い配色 | ブラウザの設定 (`prefers-color-scheme`) に従って、明るい配色と暗い配色を切り替える。画面上の切替えは置かない。暗い配色でも「配色の規則」を保ち、テーマカラーを背景に使う場所を減らして、文字にはテーマカラーを明るくした色を使う |
| 文字と背景 | 本文の文字と背景の組み合わせは、明るい配色と暗い配色のどちらでも、コントラスト比 4.5 以上にする |

## 配色の規則

色は、2 つのテーマカラーと、白・灰・黒の無彩色だけを使います。カテゴリのタグもテーマカラーで表示し、カテゴリごとに色を分けません。

| テーマカラー | 値 | 使う場所 |
| --- | --- | --- |
| 主の色 (赤紫) | `#250213` | 上部の帯、右の列の見出し、ダウンロードボタン、カテゴリのタグ、本文の見出しの帯の左の罫線 |
| 副の色 (淡い橙) | `#e2c69c` | 本文の見出しの帯、選んでいるカテゴリ。ダウンロードの枠と注意書きの背景には、副の色を淡くした色を使う |

リンクの文字は、主の色と同じ色相で明るくした `#8b1850` で表示します。主の色はほぼ黒に近く、そのままでは本文の黒い文字と見分けにくいためです。暗い配色では、主の色の背景が画面の背景に溶けないよう、帯を主の色と同じ色相で明るくした色で塗ります。リンクの文字には、同じ色相の淡い色を使います。

注意書きと検査中の状態は、副の色の背景に太い枠線と「注意」の見出しを付けて、ほかの情報と区別します。

例外の色は次の 1 つで、安全に関わる表示に限ります。

| 色 | 使う表示 | 理由 |
| --- | --- | --- |
| 赤 | 掲載停止と掲載終了の状態 | 利用者に危険の表示を見落とさせないため |

新しい色を加えるときは、この表に色・使う表示・理由を書き足してから使います。

## 文言の規則

画面と固定ページの文言は、次の規則で書きます。

- 主語を文頭に置き、主語と述語の対応を明らかにする。
- 利用者に求める行動は「〜してください」と書く。
- 1 つの文には 1 つの主張を入れる。事実だけで終わらせず、その事実を理由に利用者が取るべき行動まで 1 文で書く。
- 日本語の文言は yomiyasu で推敲する。ほかの言語の文言は、推敲した日本語の意味に合わせて書く。

全ページ共通の注意書きは、次の 2 文です。

> このプラットフォームは OBS Project と無関係の非公式で無料のサービスです。各プラグインの安全性を保証しないので、個人の責任にもとづき注意して利用してください。

配布物を GitHub から直接ダウンロードすることは、注意書きには書かず、「配信プラグイン倉庫くんとは？」のページとダウンロードボタンの近くに書きます。

## 画面の一覧

| パス | 画面 |
| --- | --- |
| `/` | トップと検索 |
| `/?q=...&os=...&category=...` | 検索結果 |
| `/?category=...` | カテゴリ別の一覧 |
| `/plugins/<owner>/<repo>` | プラグインの詳細 |
| `/about` | 配信プラグイン倉庫くんとは？ |
| `/policy` | 掲載ポリシー |
| `/submit` | プラグインを登録する (作者向け) |
| `/security` | セキュリティと免責 |
| `/report` | 通報の案内 |
| `/terms` | 利用規約 |
| `/privacy` | プライバシーポリシー |
| `/robots.txt` | 検索エンジン向けの指定 |
| `/sitemap.xml` | サイトマップ。トップと全固定ページを載せる |
| `/plugins/<owner>/<repo>/logo`・`/plugins/<owner>/<repo>/image` | プラグインのロゴと説明の画像の配信。「プラグインの画像」を参照 |
| `POST /contact` | 開発者の連絡先の表示。「全ページ共通の枠」を参照 |
| `/style.css` | スタイルシート。URL のクエリに内容のハッシュを付け、変わったときに閲覧者のキャッシュを使わせない |

詳細ページの `?orig=1` は、概要を原文で表示します。一覧の `?page=` は、ページ送りのページ番号です。`/robots.txt` は、すべてのページの収集を許し、`/mcp` だけを除外して、サイトマップの URL を示します。

## 全ページ共通の枠

画面は、上から順に次の要素で構成します。

| 要素 | 内容 |
| --- | --- |
| 上部の帯 | サービス名・キーワードの検索欄・言語の一覧。ロゴは画像を使わずサービス名の文字で表す |
| カテゴリの帯 | 左端にすべての一覧へのリンクを置き、その右にその他を除く 6 カテゴリを並べる |
| 注意書き | 「文言の規則」に書いた 2 文 |
| 本文 | 各画面の内容。右の列を除いた残りの幅 |
| 右の列 | 幅 230 px。内容は下表 |
| 下部 | 固定ページへのリンク、本サービスのソースコードへのリンク、「連絡先を表示」ボタン、「© 2026 AllegroMoltoV」の表記 |

開発者の連絡先のメールアドレスは、収集されてスパムが届くことを防ぐため、ページの HTML に書きません。下部と、通報・利用規約・プライバシーポリシーの連絡先の節には、「連絡先を表示」ボタンを置きます。ボタンはフォームの送信で、押したときだけ、サーバーが `@` を `[at]` に置き換えたアドレスを返します。スクリプトは使いません。アドレスは Worker の環境変数 `CONTACT_EMAIL` に置き、ソースコードと docs には書きません。

右の列には、本文と重ならない情報を置きます。幅 760 px 以下の表示では、右の列を本文の下へ移し、各区画を閉じた状態で表示します。区画の見出しを押すと開きます。スクリプトを使わないため、右の列は幅の広い画面用と狭い画面用の 2 通りを出し分けます。

| 区画 | 内容 |
| --- | --- |
| 新着 5 件 | 掲載中のプラグインを、このプラットフォームに登録した日の新しい順に 5 件。名前・カテゴリ・登録日 |
| 週間 DL 数ランキング 5 件 | 掲載中のプラグインを、過去 7 日間のダウンロード数の多い順に 5 件。名前と数。数が 0 のプラグインは出さない。週間の数を求められるプラグインが無いときは、区画を出さない。数は GitHub での全ダウンロードである旨を添える |
| AI エージェントから使う | MCP で接続すると会話でプラグインを探せること、OBS Studio のプラグインの作者は会話で登録できること、話しかけ方の例、`/about` の接続方法へのリンク |
| 掲載と検査について | 作者本人が登録すること、配布物を既知のマルウェアのデータベースと照合すること、検出なしは安全の保証ではないこと、`/policy` と `/report` へのリンク |
| プラグインを登録する | 作者向けに、`/submit` への案内 |
| 倉庫の状況 | 掲載中の件数と、GitHub の情報の確認日時。確認日時は、定期処理が掲載中のプラグインを最後に同期した日時 |

幅 760 px 以下の表示では、右の列を本文の下へ移します。カテゴリの帯は折り返して表示します。上部の帯では、サービス名の下の行に検索欄と言語のボタンを並べます。言語の一覧は、開いたときに本文の上へ重ねず、帯の中に広げて表示します。注意書きは短縮し、詳細へのリンクを添えます。

## カテゴリ

| 表示名 | `category` の値 |
| --- | --- |
| 音声フィルター | `audio-filter` |
| 映像フィルター | `video-filter` |
| 入力ソース | `source`。配信画面に映像や音声を足すもの |
| トランジション | `transition` |
| ドック・パネル | `dock-ui`。OBS Studio の画面にドックやパネルを足すもの |
| 配信・録画 | `output` |
| その他 | `other`。どれにも当たらないもの |

カテゴリは、作者が登録のときに選びます。選ばなかった場合は自動で推定し、管理者は管理コマンドで直せます。OBS Forums のリソースの分類は OBS Studio Plugins の中を種類で分けていないため、OBS Studio の画面で使う言葉で分けています。カテゴリはテーマカラーのタグで表示します。推定の規則は [検査と同期](scanning.md) に記載します。

## トップと検索

| 要素 | 内容 |
| --- | --- |
| 検索フォーム | キーワードの入力欄と、OS とカテゴリの選択。OS の選択肢はすべて・Windows・macOS・Linux |
| 新着・更新 | 掲載中のプラグインのカード。並び順とページ送りは「検索結果とカテゴリ別の一覧」と同じ |

プラグインのカードは、ロゴ・名前・掲載対象バージョン・カテゴリのタグ・対応 OS のタグ・概要・作者・更新日・ダウンロード数を表示します。更新日は、掲載対象バージョンの公開日です。概要が自動翻訳のときは、自動翻訳である旨を短く添えます。原文を表示するリンクは詳細ページに置きます。ダウンロード数の記録が無いプラグインでは、ダウンロード数を表示しません。ロゴが無いプラグインでは、ロゴの場所を空けずに表示します。カードには状態のバッジを出しません。

## 検索結果とカテゴリ別の一覧

| 要素 | 内容 |
| --- | --- |
| 見出し | 検索語またはカテゴリと、件数 |
| 絞り込み | OS とカテゴリ |
| 並び順 | 掲載対象バージョンの公開日の新しい順 |
| 一覧 | トップと同じ形のカード |
| ページ送り | 前へ・現在のページと総ページ数・次へ。1 ページは 20 件 |

## プラグインの詳細

掲載中のプラグインの詳細ページは、上から順に次の要素で構成します。

| 要素 | 内容 |
| --- | --- |
| パンくずリスト | ライブラリとカテゴリ |
| 見出し | ロゴ・名前・カテゴリのタグ・概要。掲載中であることは表示しない。一覧と詳細には掲載中のプラグインしか出ないため |
| 説明の画像 | 作者が用意した画像 1 枚。GIF はアニメーションとして再生する。画像が無いプラグインでは表示しない |
| ダウンロードボタン | GitHub の配布物へ直接リンクする。掲載対象バージョン・配布物名・サイズを添える |
| 基本情報 | 作者・対応 OS・対応 OBS バージョン・ライセンス・バージョンと公開日・コミット SHA・GitHub リポジトリへのリンク・GitHub のリリース一覧へのリンク・ダウンロード数 (GitHub) と集計日 |
| 配布物と検査 | 配布物ごとの名前・SHA-256・検査結果・検査日時。スキャナーごとの結果。検出なしは安全の保証ではない旨 |
| 検査中の新しいバージョン | 掲載対象より新しいリリースが検査中のとき、その旨と、検査が終わるまで掲載対象バージョンを示す旨 |
| 注意事項 | 配布物は作者が GitHub で公開したものであること、導入前に作者の説明を読むこと |
| 通報 | `/report` へのリンク |

対応 OBS バージョンは、確認できない場合に確認できない旨を表示します。ダウンロード数は、新しい順に最大 100 件のリリースの配布物の、GitHub でのダウンロード数の合計です。このサイトを経由したものに限らない旨を添えます。記録が無い場合は、ダウンロード数の行を表示しません。

右の列には、全ページ共通の区画の前に、この作者のプラグインと、同じカテゴリのプラグインを掲載対象バージョンの公開日の新しい順に置きます。

掲載中以外のプラグインの詳細ページは、次の要素だけで構成します。ロゴ・説明の画像・ダウンロードボタン・概要・配布物と検査の区画は表示しません。応答には `X-Robots-Tag: noindex` を付け、検索エンジンに載せません。

| 要素 | 内容 |
| --- | --- |
| パンくずリストと見出し | 名前・カテゴリのタグ・状態のバッジ (検査中、掲載停止、掲載終了) |
| 案内文 | 検査待ちでは、検査を通るとダウンロードの案内を表示する旨。停止では、掲載を停止している旨。掲載終了では、GitHub で公開されなくなった旨 |
| 理由 | 停止で、管理停止の理由が設定されている場合だけ表示する |
| 通報 | `/report` へのリンク |

右の列には、全ページ共通の区画だけを置きます。

## プラグインの画像

プラグインには、ロゴと説明の画像を 1 枚ずつ掲載できます。作者は画像をリポジトリに置き、本サービスは同期のときに取得して自分のドメインから配信します。取得の規則は [検査と同期](scanning.md) に、配信の判断は [ADR 0011](../decisions/0011-plugin-images-hosted-by-worker.md) に記載しています。

| 項目 | ロゴ | 説明の画像 |
| --- | --- | --- |
| 表示する場所 | カードと詳細ページの見出し | 詳細ページの見出しの下 |
| 表示の大きさ | カードでは 48 px 四方、詳細ページでは 64 px 四方に収める | 本文の幅に収める |
| 代替テキスト | 空にする。名前を隣に表示するため | 「<名前> の説明の画像」 |

画像には `width` と `height` を指定し、読み込みの前後で配置がずれないようにします。カードの画像は、画面に入るまで読み込みを遅らせます。スクリプトを使わないため、動きを減らす設定の閲覧者に対しても GIF の再生を止められません。

## 固定ページ

| パス | 内容 |
| --- | --- |
| `/about` | 配信プラグイン倉庫くんとは？ サービスの目的、非公式であること、配布物を GitHub から直接ダウンロードすること、Claude Code と Codex での MCP の接続方法と話しかけ方の例 |
| `/policy` | 掲載ポリシー。掲載の条件、AI の使用の有無を掲載の条件にしないこと、掲載は安全性や品質の認証ではないこと |
| `/submit` | 作者向けに、登録の条件、MCP の接続とサインイン、話しかけ方の例、登録後の流れ (検査に要する時間と状態の変化)、登録が拒否されたときの理由と直し方の一覧 (`submit_plugin` が返すすべての理由コード)、配布物を VirusTotal へアップロードする案内、ロゴと説明の画像の置き方、更新と掲載の取り下げの方法 |
| `/security` | 検査の内容と限界、掲載は安全性の保証ではないこと、免責 |
| `/report` | 公開してよい内容は GitHub Issues、マルウェアの疑いのような非公開の内容は GitHub の Private vulnerability reporting で受け付けること。開発者の連絡先 |
| `/terms` | 利用規約。このプラットフォームが提供するものと提供しないもの、登録する作者が守ること、禁止する行為、掲載の停止と削除、免責、規約の変更、準拠法 (日本法) と管轄 (運営者の住所地を管轄する地方裁判所)、連絡先 |
| `/privacy` | プライバシーポリシー。保存する個人情報と利用目的、連絡先 |

正とする版以外の固定ページには、翻訳は参考である旨と、正とする版へのリンクを表示します。利用規約とプライバシーポリシーは日本語版、ほかの固定ページは英語版を正とします。言語の仕様は [多言語対応](i18n.md) に記載します。
