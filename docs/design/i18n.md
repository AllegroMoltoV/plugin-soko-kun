# 多言語対応

Web カタログの対応言語・言語の判定・翻訳の対象範囲の仕様です。

## 対応言語

| 言語タグ | 言語 |
| --- | --- |
| `en` | 英語 |
| `ja` | 日本語 |
| `zh-Hans` | 中国語簡体字 |
| `zh-Hant` | 中国語繁体字 |
| `ko` | 韓国語 |
| `pt-BR` | ブラジルポルトガル語 |
| `es-419` | 中南米スペイン語 |

上の 7 言語以外には対応しません。

## 言語の判定

Web カタログは、次の順に表示する言語を決めます。最初に 7 言語のいずれかに決まった時点で判定を終えます。

| 順序 | 判定の材料 |
| --- | --- |
| 1 | クエリパラメーター `?lang=` |
| 2 | cookie |
| 3 | 要求ヘッダー `Accept-Language` |
| 4 | 上のいずれでも決まらない場合は日本語 |

ブラウザーの言語が 7 言語に該当しない場合と、言語を判定できない場合は、日本語で表示します。

`Accept-Language` の値と 7 言語の言語タグとの対応づけの規則は未決定です。たとえば `zh-TW` を `zh-Hant` に、`es-MX` を `es-419` に対応づける規則が対象です。cookie を書き込む条件も未決定です。

利用者は、全ページの上部にある言語の一覧から言語を切り替えられます。各ページは、他の言語の版を `hreflang` で示します。

## 翻訳の対象範囲

| 対象 | 言語 |
| --- | --- |
| 画面の文言 | 7 言語 |
| 固定ページの本文。`/about`・`/security`・`/report`・`/privacy` | 7 言語。英語版を正とする |
| プラグインの概要・リリース名・配布物名 | GitHub の原文のまま。翻訳しない |
| MCP のツールの説明と応答 | 英語のみ |

英語以外の固定ページには、翻訳は参考であり英語版が正である旨と、英語版へのリンクを表示します。

画面の文言の辞書は `src/web/i18n/<言語タグ>.json` に置きます。
