# 多言語対応

Web カタログの対応言語・言語の判定・翻訳の対象範囲の仕様です。

## 対応言語

| 言語タグ | 言語 |
| --- | --- |
| `en` | 英語 |
| `ja` | 日本語 |
| `zh-Hans` | 中国語簡体字 |
| `zh-Hant` | 中国語繁体字 |
| `ko` | 韓国語 |
| `pt-BR` | ブラジルポルトガル語 |
| `es-419` | 中南米スペイン語 |

上の 7 言語以外には対応しません。

## 言語の判定

Web カタログは、次の順に表示する言語を決めます。最初に 7 言語のいずれかに決まった時点で判定を終えます。

| 順序 | 判定の材料 | 採る条件 |
| --- | --- | --- |
| 1 | クエリパラメーター `?lang=` | 値が 7 言語の言語タグのいずれかと完全に一致する |
| 2 | cookie `lang` | 値が 7 言語の言語タグのいずれかと完全に一致する |
| 3 | 要求ヘッダー `Accept-Language` | 下表の規則で 7 言語のいずれかに対応づけられる |
| 4 | 上のいずれでも決まらない | 日本語 |

`Accept-Language` は、q 値の大きい順に言語タグを評価します。q 値が 0 の言語タグは使いません。言語タグは大文字と小文字を区別せず、次の規則で対応づけます。

| 言語タグ | 対応する言語 |
| --- | --- |
| `ja` で始まる | `ja` |
| `en` で始まる | `en` |
| `ko` で始まる | `ko` |
| `zh-TW`・`zh-HK`・`zh-MO` で始まる、または `Hant` を含む `zh` | `zh-Hant` |
| 上記以外の `zh` で始まる | `zh-Hans` |
| `pt` で始まる | `pt-BR` |
| `es` で始まる | `es-419` |
| 上記のいずれにも該当しない | 次の言語タグを評価する |

### cookie

`?lang=` で言語が決まり、その値が cookie の値と異なる場合に、cookie `lang` を書き込みます。

| 属性 | 値 |
| --- | --- |
| `Path` | `/` |
| `Max-Age` | 1 年 |
| `SameSite` | `Lax` |
| `Secure` | `ORIGIN` が `https:` で始まる場合だけ付ける |

応答には `Vary: Accept-Language, Cookie` を付けます。

### 言語の切替え

利用者は、全ページの上部にある言語の一覧から言語を切り替えられます。一覧のリンクは `?lang=` を付けた URL です。各ページは、7 言語の版を `hreflang` で示します。`x-default` は英語版を示します。

## 翻訳の対象範囲

| 対象 | 言語 |
| --- | --- |
| 画面の文言 | 7 言語 |
| 固定ページの本文。`/about`・`/policy`・`/submit`・`/security`・`/report` | 7 言語。英語版を正とする |
| 利用規約とプライバシーポリシー。`/terms`・`/privacy` | 7 言語。日本語版を正とする |
| プラグインの概要 | 画面の言語へ機械翻訳して表示する。自動翻訳である旨と、原文を表示するリンクを添える。翻訳が無い場合は原文を表示する |
| リリース名・配布物名 | GitHub の原文のまま。翻訳しない |
| MCP のツールの説明と応答 | 英語のみ。プラグインの概要は原文を返す |

正とする版以外の固定ページには、翻訳は参考である旨と、正とする版へのリンクを表示します。

画面の文言の辞書と言語の判定は `src/web/i18n.ts` にあります。固定ページの本文は `src/web/content.ts` にあります。
