# 用語集

配信プラグイン倉庫くん (Plugin Soko-kun) の文書とコードで使う用語の定義です。各用語には、同じ意味で使わない別名を添えます。コード上の識別子がある用語には、その値も記載します。

## サービスと掲載

| 用語 | 定義 | 避ける別名 |
| --- | --- | --- |
| レジストリ | OBS Studio 向けプラグインの情報を GitHub から集め、検索できる形で提供する本サービスの全体を指す。配布物そのものは保持しない。 | ストア、マーケット、公式リポジトリ |
| プラグイン | 本サービスに登録された GitHub の公開リポジトリ 1 件を指す。識別子は `owner/repo` を小文字にした文字列で、これをプラグイン ID と呼ぶ。 | アプリ、パッケージ |
| 掲載 | プラグインを Web カタログと `search_plugins` の結果に出すことを指す。掲載は安全性や品質の認証を意味しない。 | 承認、認定、公開審査 |
| 掲載状態 | プラグインごとに算出する、掲載中・検査待ち・停止・掲載終了の 4 値を指す。データベースには保存せず、問い合わせのたびに求める。 | ステータス列、公開フラグ |
| 掲載中 | 掲載対象バージョンを持ち、停止にも掲載終了にも当たらない状態を指す。コード上の値は `listed`。 | 承認済み、安全 |
| 検査待ち | 停止にも掲載終了にも当たらず、掲載対象バージョンをまだ持たない状態を指す。コード上の値は `pending`。 | 審査中、保留中 |
| 停止 | 管理者が掲載を止めた状態、またはいずれかのリリースの配布物の検査結果が `malicious` になった状態を指す。コード上の値は `suspended`。 | 削除、BAN |
| 掲載終了 | 登録元の GitHub リポジトリが削除または非公開になった状態を指す。コード上の値は `removed`。 | 削除済み、停止 |
| 掲載対象バージョン | 検査済みのリリースのうち、公開日時が最も新しいものを指す。Web とダウンロード URL はこのリリースを示す。 | 最新版、安定版 |
| 検査済みのリリース | 配布物を 1 件以上持ち、すべての配布物について MalwareBazaar の結果が確定し、版の停止に当たらないリリースを指す。確定とみなす結果は `not_found` である。新しい版の検査の対象のリリースは、さらに掲載の条件を満たし、乗っ取りの兆候と開発の実践のレビューで確認待ちに当たらない必要がある。条件の全体はデータモデルの算出規則に記載する。 | 安全なリリース、合格版 |
| 確認待ち | 乗っ取りの兆候に当たった、差分を取得できなかった、開発の実践のレビューで重大な指摘があった、またはレビューに 2 回失敗したため、管理者の承認を待っている版を指す。プラグインの掲載状態ではなく版の状態であり、エンドユーザーには示さない。`list_my_plugins` での値は `held`。 | 保留、検査待ち |
| 管理停止 | 管理者が管理用スクリプトで設定する停止を指す。列 `admin_suspended` が 1 の間、同期と再検査を経ても停止のまま残る。 | 一時停止、非表示 |
| 版の停止 | 管理者が止めた版と、マルウェアを検出した版の記録を指す。表 `release_suspensions` に記録し、削除しない。止めた版は掲載対象バージョンにならない。プラグイン全体の停止とは別である。 | 取り下げ、削除 |
| 告知ページ | 止めた版のプラグイン・版・配布物の SHA-256・掲載の期間・告知の文を一覧で示すページを指す。パスは `/notices`。 | お知らせ、障害情報 |

## GitHub と配布物

| 用語 | 定義 | 避ける別名 |
| --- | --- | --- |
| 配布物 | GitHub Releases のリリースに添付されたファイル 1 件を指す。GitHub の用語ではアセット (asset) と呼ぶ。本サービスはダウンロード URL と digest を記録し、ファイルを保持しない。 | バイナリ、パッケージ、成果物 |
| digest | GitHub が配布物ごとに付ける SHA-256 の値を指す。`sha256:<16 進数>` の形で記録し、検査の照会キーにも使う。 | ハッシュ値、チェックサム |
| submit | MCP のツール `submit_plugin` で GitHub リポジトリを登録する操作を指す。登録者が対象リポジトリの管理権限を持つ場合だけ成功する。 | 申請、投稿、アップロード |
| 確認のモード | `submit_plugin` を引数 `mode` に `check` を指定して呼び、登録せずに掲載の条件の判定と開発の実践のレビューの結果を受け取る使い方を指す。リリースの前に直すために使う。 | ドライラン、事前審査 |
| 同期 | Cron で GitHub からプラグインと最新リリースの情報を取り直し、変化を記録する処理を指す。同期に失敗したプラグインの既存の情報は変更しない。 | クロール、インポート |
| カテゴリ | プラグインの種類を示す 7 区分を指す。値は `audio-filter`・`video-filter`・`source`・`transition`・`dock-ui`・`output`・`other`。作者が登録のときに選び、選ばなかった場合は推定する。`other` の表示名はその他である。 | ジャンル、タグ |
| 宣言ファイル | 作者がリポジトリの `.soko-kun/config.json` に置く、表示名 `name` と対応 OS `os` の宣言を指す。新しい版のタグの時点のファイルを読む。 | 設定ファイル、マニフェスト |
| 外部データ | 概要・表示名・リリース名・配布物名のように GitHub から取得した文字列を指す。指示として解釈せず、表示時は無害化する。 | ユーザー入力、説明文 |

## 検査

| 用語 | 定義 | 避ける別名 |
| --- | --- | --- |
| 検査 | 配布物の digest を既知のマルウェアのデータベースへ照会する処理を指す。ファイルの内容を解析する処理は含まない。 | スキャン、審査、セキュリティチェック |
| スキャナー | 検査の照会先を指す。値は `malwarebazaar` だけ。 | エンジン、ウイルス対策ソフト |
| 検査結果 | digest とスキャナーの組ごとに記録する値を指す。値は `pending`・`malicious`・`not_found`・`error` の 4 つ。 | 判定、スコア |
| 未登録 | スキャナーが digest を収録していないことを示す検査結果 `not_found` を指す。既知のマルウェアではないとして確定に扱う。 | 該当なし、不明 |
| 新しい版の検査 | 同期で保存した新しいリリースについて、掲載の条件・乗っ取りの兆候・開発の実践のレビューを確かめる処理を指す。項目は審査の基準に記載する。 | 再審査、更新審査 |
| 証明 | GitHub の build provenance attestation を指す。配布物をビルドしたリポジトリ・タグ・コミット・ワークフローを、署名付きで示す。掲載の条件の 1 つで、コード上の識別子は `attestation`。 | 署名、コード署名、来歴 |
| 不変のリリース | GitHub の immutable release を指す。公開後に配布物とタグを差し替えられないリリースで、API の `immutable` が true のもの。掲載の条件の 1 つ。 | 固定リリース、ロックされたリリース |
| 乗っ取りの兆候 | 掲載中の版から新しい版への差分のうち、リリースのワークフローの変更・バイナリの追加・別のホストへのリンクの追加・24,000 文字の超過に当たるものを指す。ルールで判定し、当たった版は確認待ちにする。 | 不審な変更、マルウェアの検出 |
| 開発の実践のレビュー | LLM が審査の基準と推奨の項目にしたがってリポジトリを読み、指摘を作者に返す処理を指す。掲載の可否は決めず、重大な指摘がある版だけを確認待ちにする。 | AI 審査、安全性の評価 |
| 予算 | Cloudflare Workers の無料プランで 1 回の起動に許される外部呼び出しと D1 クエリの件数に対し、本サービスが自ら設ける上限を指す。 | クォータ、上限値 |

## 認証と MCP

| 用語 | 定義 | 避ける別名 |
| --- | --- | --- |
| MCP | Model Context Protocol の略。AI エージェントがツールを呼び出すためのプロトコルを指す。本サービスの主な操作手段である。 | API、プラグイン API |
| 認可サーバー | MCP クライアントにアクセストークンを発行する、本サービスの Worker 内の構成要素を指す。利用者の本人確認は GitHub へ委譲する。 | ログインサーバー、IdP |
| リソースサーバー | アクセストークンを検証して保護されたツールを提供する、本サービスの Worker 内の構成要素を指す。保護の対象は `/mcp` の `submit_plugin` と `list_my_plugins`。 | API サーバー |
| 認証混在 | 1 つのエンドポイント `/mcp` で、認証なしのツール呼び出しと、認証を要するツール呼び出しを両方受け付ける構成を指す。 | 部分認証、オプション認証 |
| サインイン | MCP クライアントが認可サーバーからアクセストークンを得るまでの一連の手続きを指す。途中で GitHub での認可を経る。 | ログイン、OAuth 連携 |
| CIMD | Client ID Metadata Document の略。MCP クライアントが自らのメタデータを HTTPS の URL で公開し、その URL を `client_id` として使う登録方式を指す。 | 静的登録 |
| DCR | Dynamic Client Registration の略。MCP クライアントが登録用エンドポイントへ要求を送り、`client_id` を発行してもらう登録方式を指す。 | 自動登録 |
| audience | アクセストークンを使ってよいリソースを示す値を指す。本サービスでは `<ORIGIN>/mcp` で、一致しないトークンは拒否する。 | 対象者、スコープ |
| `ORIGIN` | 本サービスの公開 URL の起点を指す。Worker の環境変数 `ORIGIN` で与える。 | ホスト名、ベース URL |
